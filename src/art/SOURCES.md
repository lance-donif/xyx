# 自然素材

下列摄影扫描素材以 CC0 发布。游戏随包提供压缩的 WebP，运行时从本站加载。

| 文件 | 来源及处理 |
| --- | --- |
| grass.webp | [ambientCG Grass 005](https://ambientcg.com/a/Grass005)，缩小并调整饱和度 |
| rock.webp | [Poly Haven Rock Boulder Dry](https://polyhaven.com/a/rock_boulder_dry)，缩小 |
| asphalt.webp | [Poly Haven Asphalt 04](https://polyhaven.com/a/asphalt_04)，缩小 |
| dirt.webp | [Poly Haven Brown Mud Dry](https://polyhaven.com/a/brown_mud_dry)，缩小 |
| bark.webp | [Poly Haven Bark Brown 01](https://polyhaven.com/a/bark_brown_01)，缩小 |
| oak-foliage.webp | [Poly Haven Tree Small 02](https://polyhaven.com/a/tree_small_02)，在 Blender 中单独渲染两个角度的树冠，保留枝叶遮阴，分层组合为阔叶图集 |
| spruce-foliage.webp | [Poly Haven Fir Sapling Medium](https://polyhaven.com/a/fir_sapling_medium)，在 Blender 中对两株模型布光渲染、组合为针叶树图集 |
| meadow-tuft.webp | [ambientCG Foliage 001](https://ambientcg.com/a/Foliage001)，组合并着色为一簇草 |
| alpine-ridgeline.webp | [Poly Haven Alps Field](https://polyhaven.com/a/alps_field)，从 4K 全景沿实拍山脊抠出远景，加入空气透视 |

elderwood-vista.webp 为本项目使用图像生成工具创作的巨木山谷远景，游戏将绘景与可骑行的三维山脊叠合。
